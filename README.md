Console-Based Calculator in Java

A simple console-based calculator built using Java. This project performs basic arithmetic operations like addition, subtraction, multiplication, and division through user input.

Features

Addition

Subtraction

Multiplication

Division

User-friendly console interaction

Error handling for division by zero


Technologies Used

Java

IntelliJ IDEA


How It Works

1. User enters two numbers.


2. User selects an operation.


3. Program performs the calculation.


4. Result is displayed on the console.



Sample Output

Enter first number: 10
Enter second number: 5
Choose operation (+, -, *, /): *
Result: 50
